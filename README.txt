FORMULA
If these A1 and 2 have the same value, B2 is computed to 1, else 2. The pattern repeats for all values in A. THe same formula runs for the C column but it references B2 onwards. D column references C3 onwards.

When you enter either the latest D or A value, the remaining columns are computed abiding by the pattern.

INITIALIZATION
To initialize the row, type 1 or 2 to A1, A2, A3, and A4. 
B1, C1, C2, D1, D2, D3 are blank by design.
